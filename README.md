# Geospatial Data Standardization (Pho Map Project)

### Project Overview
This project involved cleaning and standardizing a large-scale geospatial database of Vietnamese restaurants across Europe (France, Switzerland, etc.) to support the launch of the "Pho Map."

### Key Tasks & Methodology
* **Data Cleaning:** Handled inconsistent naming conventions, addresses, and country codes using **Python (Pandas)**.
* **String Manipulation:** Applied advanced string processing to extract and reformat contact details and location data from unstructured fields.
* **Quality Assurance:** Standardized geolocation-related fields to ensure data integrity for map integration.

### Technical Impact
Transformed raw, inconsistent data into a structured format ready for database migration (WordPress) and map visualization, ensuring high accuracy for over hundreds of locations.
